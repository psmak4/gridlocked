# M0 Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an empty but real Gridlocked app with every tool and guard rail in place:
- type-checked;
- linted;
- unit, database and E2E tested;
- themed from the design system;
- checked by CI on every PR.

**Architecture:** one Next.js App Router app (no monorepo). Pure helpers live in `src/lib/`. The database layer in `src/db/` uses Drizzle and SQL migrations, tested against PGlite (in-process Postgres 17). Design tokens in `src/design/` are the single typed source for the CSS variables Tailwind reads.

**Tech Stack:**
- Node 24 LTS, pnpm 10, TypeScript (strict);
- Next.js (latest stable 16.x at install) with React 19, Tailwind CSS 4;
- Drizzle ORM and drizzle-kit, `@electric-sql/pglite`;
- Vitest, Playwright;
- the `uuidv7` package;
- GitHub Actions.

**Spec:** [docs/design/04-implementation-plan.md](../design/04-implementation-plan.md) (M0), with DM 0.2–0.3, DM 2.11, DM 3.7, the design system README, and UI brief "Fixed constraints".

## Global Constraints
- **No cloud resources** are created in M0: no Neon, Vercel, Resend or Sentry. Everything runs locally and in GitHub Actions.
- **Versions:** Node `24` (pinned in `.nvmrc` and `package.json` `engines`); pnpm `10` via `packageManager`. Install the latest stable of each library and commit the lockfile.
- **TypeScript:** `strict: true` and `noUncheckedIndexedAccess: true`.
- **IDs** are UUIDv7 strings generated by the app (DM 0.2).
- **Money** is integer units of $0.1M: `234` means $23.4M and `1000` means $100M (DM 0.3).
- **The clock:** all "now" reads go through the injectable clock (HLD §3.3 rule 6). In SQL, `app_now()` reads the `simulated_clock` setting, else `now()` (DM 3.7).
- **Theme:** light is the first theme and the fallback. Dark applies with `data-theme="dark"` or when the device prefers dark and nothing was chosen (UI brief decisions).
- **Fonts:** Anton (display), Barlow (text), Barlow Semi Condensed (numbers), via `next/font/google`.
- **Footer copy, exact:** `Unofficial. Not affiliated with Formula 1 or the FIA. Data from Jolpica and OpenF1.`
- **Workflow:** each task is one branch `m0/<issue>-<slug>` and one PR that closes its issue.

## Review Focus
1. **Code that reads the real time directly** (`Date.now()`, a no-argument `new Date()`) bypasses the replay clock. Expected: lint fails outside `src/lib/clock.ts`. *Pinned in Task 2.*
2. **A wrong-theme flash on first paint.** Expected: the `<html>` element already has the right `data-theme` before React hydrates. *Pinned in Task 7.*
3. **Malformed money strings** (`"23.4"`, `"$23.45M"`, `"$-1M"`, `""`). Expected: a clear error, never a silent 0. *Pinned in Task 4.*
4. **A malformed `simulated_clock` setting.** Expected: `app_now()` raises an error rather than quietly falling back to real time on a replay branch. *Pinned in Task 5.*
5. **Two test databases in one run.** Expected: each test gets a fresh, fully migrated database, with nothing leaking between tests. *Pinned in Task 5.*

    | Column | Type |
    |---|---|
    | `key` | `text` primary key |

    | `updated_at` | `timestamptz not null default now()` |
